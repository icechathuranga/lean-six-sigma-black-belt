Hypothesis Test Planner — [Question]

⬇ Download editable template (DOCX)

One page per test. Decide everything before you look at the result. Module 07.

StepYour entry
1. Practical questione.g. "Did the new pre-screen cut time-to-hire?"
2. Output (Y) & type___ (continuous / discrete)
3. Input (X) & type___ (group / continuous)
4. H₀ (no difference/effect)
5. H₁ (the effect)one-sided / two-sided
6. Test chosen(see which-statistical-test cheat sheet)
7. α (significance)0.05
8. Sample size / powern = ___ (target power 0.80)
9. Check assumptionsnormality? equal variance? independence?
10. Resultstatistic = ___ p = ___
11. Decisionp < α → reject H₀ (significant) / else fail to reject
12. Practical conclusioneffect size + is it worth acting on?

Worked: datasets/before-after-tth.csv → Welch t = 2.88, p = 0.0061 → reject H₀; mean fell 31.0 → 26.6 days (a ~4.4-day, practically useful reduction).
