All numbers below were computed with numpy/scipy/statsmodels (seed-fixed). Lesson authors MUST use these exact figures.

1. Multiple regression — time-to-hire-regression.csv

R-squared = 0.661, adj R2 = 0.652, F p-value = 3.84e-27 coef Intercept: 9.016 (p=1.13e-07) coef interview_rounds: 3.448 (p=6.64e-19) coef offer_delay_days: 1.979 (p=3.59e-09) coef recruiter_caseload: 0.373 (p=2.49e-09) => each extra interview round adds ~3.4 days; model explains ~66% of variation.

2. One-way ANOVA — time-to-hire-by-region.csv

group means (days): {'East': 24.5, 'North': 26.8, 'South': 30.0, 'West': 32.2} ANOVA F = 15.01, p = 2.54e-08 => regions differ significantly

3. Gage R&R (ANOVA method) — interview-score-gagerr.csv

repeatability var=3.13, reproducibility var=3.45, part var=62.28 %GRR (contribution)=9.6%, %GRR (study var)=30.9%, ndc=4 => rule of thumb: %study <10% good, 10-30% marginal, >30% unacceptable; ndc>=5 desired. Here %study=31%.
